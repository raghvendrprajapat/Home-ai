# Static asset tools

Run from repository root with pinned Node24.19.0/pnpm11.19.0:

```sh
pnpm install --frozen-lockfile
pnpm assets:build
pnpm assets:check
pnpm assets:versions
pnpm check
```

`build` is explicit and changes only generated `apps/web/public/catalog`. `check` regenerates/computes actual GLB validation and compares without writing. `versions` checks immutable historical entries against `origin/main` locally or the explicit `GHARPLAN_ASSET_BASE_SHA` in CI; fetch that baseline when working from a shallow checkout. Missing/unreadable baselines fail. GitHub workflow wiring supplies and fetches PRbase/pushbefore, or first parent for manual dispatch. Tests belong to required `pnpm check`; the actual Node test runner must execute10cases, not merely report a wrapper file.

Sources are `sources/a_<name>-v<integer>.json`, with exact fields from `validateSource` in model.mjs. Keep a source for every historical version and its fixed metadata. Never rewrite a published version: copy to a new filename/version and retain old entries. The current profile accepts original axis-aligned boxes with integer-mm centre/size and solid colors, not arbitrary glTF imports. Compile-time normalized world bounds must match dimensions, with baseY0 and centredX/Z. Canonical project snapshots and integer-coordinate rules are unchanged.

Generated catalog entries include sourceSHA256, dimensions, source/provenance/app-use rights, official validator results, LOD hashes/bytes/placed-triangle counts and thumbnail hashes/size. The pilot desk has72triangles and no textures, so both budgets use the same2740byteGLB; no mesh simplification/compression claim. Its256pxSVG preview is stylized. AST-003's oldminZ0 typo is corrected by D39: glTF usesYup; the drawer faces−Z.

The original procedural source and outputs were generated by Codex for this authorized project, with owner rights retained. `project-original-app-use` records app use, including commercial use/app redistribution, and does not grant standalone redistribution or dedicate the asset toCC0. No third-party art/model was copied. Record validation is not a legal opinion or proof of exclusive copyrightability. Do not mark an external model as project-original. External licensing support/curation requires a separately evidenced contract.

Publication is single-writer: validate/preflight, atomic sibling-file replacements, verifyblobs, renamecataloglast. Matching old blobs are never rewritten. Failure before publication preserves prior referenced files; a stopped process can leave its own temporaries/neworphanblobs. Checks report these; inspect them rather than deleting unknown files. No fsync/OS-crash/concurrent-writer guarantee is made.

Standalone browser compatibility proof (start `pnpm dev` first):

```sh
python docs/verification/scripts/ph4-t01-asset.py
```

It uses disposable Chromium151/SwiftShader, a temporary HTML it removes, and actual Three GLTFLoader/readback. It does not open a project or implement a catalog screen. See [D39](../../docs/decisions/static-asset-pipeline.md). Generic textures/KTX2 are deferred from this small untextured foundation. D36 requires permission for R2/account/cloud delivery, device compression/testing, subscriptions/security/privacy/release/finalClaude; those scopes remain unstarted. Catalog UI/asset placement and non-device-specific material work follow separately under D17.
