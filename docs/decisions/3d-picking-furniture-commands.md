# D38 — 3D picking and shared furniture adjustments

PH3-T05, Codex under D17/D36, 2026-10-15. Base: PR84 merge438d1756b4c8f8c5b06411adc2045c45d3187983. No new dependency, schema or accepted independent fixture changes.

3D selection resolves visible geometry to canonical IDs: ordinary meshes, structural batch triangle ranges and furniture instance indices. Visibility is checked through ancestors because Three raycasting does not itself enforce the display visibility contract. Hidden originals, hidden ceilings and separate selection helpers never intercept a pick. Door/window voids have logical opening boxes, without introducing rendered solids; a closer visible object still occludes them. Nearest distance wins, with stable kind/ID tie ordering. CPU raycasting is adequate for current bounded scenes; larger catalog scenes require measured investigation rather than an unverified performance claim.

Document pointer capture tracks all held IDs, including fingers starting outside the canvas. Only a primary-button single-pointer release within6CSSpx of its start and the same four-domain async tag can select. Orbit, pinch, cancellation, pending/stale scenes, graphics loss and recovery reject selection. Scroll/blur/visibility changes cancel the candidate while retaining held IDs until up/cancel; only renderer teardown clears all ownership. If an OS permanently loses release/cancel events, reopening3D resets this conservative block. Selection never changes project content or history.

The shared 2D/3D Furniture adjustments form stages explicit-unit X/Y/elevation, rotation and relative uniform scale. Apply constructs exactly one UpdateFurniture command at the captured generation. Coordinates convert once to integer millimetres; uniform dimensions use exact decimal rational half-up rounding once per dimension. Rotation is finite and normalized into[0,360); elevation is0…6000mm. Invalid values, stale drafts, Reset and unchanged submissions leave canonical content/history unchanged. Existing core validation remains authoritative. No renderer writes the model; save/reload and Undo/Redo consume the same canonical document. Selection-list, marquee, clear and duplicate operations update the active furniture form and3D helper together.

The selection outline owns an independent two-resource cache, allocated lazily and retained after clear for reuse. Renderer close/failure disposes it exactly once. Furniture uses its actual rotated/scaled/elevated transform, while structural entities use bounding boxes; an L-shaped room outline is therefore a bounds indicator, not its room polygon. The helper never alters canonical materials, cannot be picked and is hidden synchronously during PNG capture before safe restoration.

Camera pose terminology correction: existing transient vectors round to12decimal places in metres (1e-12m), not nanometres. This guards floating-point recreation drift; it is not a physical measurement accuracy claim.
