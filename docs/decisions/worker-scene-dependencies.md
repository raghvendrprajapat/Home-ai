# D34: worker request ownership and conservative dependencies

PH3-T02, Codex under D17,2026-10-14. No dependency, schema or accepted-fixture change. Spec §G.4–G.5; SYNC-001/006.

Each worker has one monotonic request ID and one captured four-domain tag: project, session, generation and document dependency hash. A reply must belong to the active ID, match its captured tag, then still match the current store. Idle/old duplicates cannot cancel/extend a newer deadline, release its busy state or apply twice. Matching stale replies request only the latest snapshot; intermediate edits coalesce. Worker verifies request ID, document project and document hash before building. Copies of typed arrays are transferred; cached buffers remain owned and attached.

Current worker build errors, post failures, runtime errors and the10s deadline terminate once, detach handlers, unsubscribe and ignore late callbacks. The model remains editable; switching2D→3D starts a fresh pipeline. Stale errors are ignored. A previous complete GPU group can be displayed after failure without applying it to newer model data: explicit previous-scene message/generation, no current rendered-generation or onFrame success/performance reading. Context-restored UI must retain the pipeline failure label. Synthetic context events verify label state only; real GPU loss/rebuild belongs to PH3-T04.

The dependency graph considers both old and new relationships: moved junctions/incident and neighbor wall caps, openings/host bodies, touching rooms, room finishes→door thresholds, floor elevation→all surfaces/furniture bounds, material UV→dependent buffers, and deleted IDs. Its local dirty IDs are conservative advisory diagnostics. Thick-strip overlaps and shared collinear triangulation make complete orthogonal union/shared-edge analysis the correctness authority; structural edits still run that analysis, then complete per-surface signatures reuse unaffected meshes.

The exact geometry projection omits project/room names, room type/rev, wall rev, unit labels, camera/light metadata, furniture transforms and material color/roughness/metalness. Those retain cached structural surfaces; GPU adapter/materials/bounds still update from the current canonical document. Floor elevation, junctions, wall/opening shape/hosts, room boundaries/heights/finishes and material IDs/UV scales remain dependencies. Baked UV changes regenerate dependent buffers, an explicit exception to §G.5's material-only swap; future shader UV transforms can remove it with tests. Cache ownership advances only after a successful derivation, never after a failed one.

Metadata cache hits skip scene geometry construction, but the worker still calls full validateProject/topology validation and copies/transfers buffers. This is not a measured total-CPU or large-plan/phone optimization result. Invalid drawings are never committed for the renderer to repair.

Codex tests cover captured/current tag substitution, duplicates/deadlines, all four tag domains, coalescing/Undo, terminal cleanup/late callbacks, actual transferred buffers, projected metadata/UV and old/new graph relationships with seeded properties. Browser tests delay actual worker delivery, replay old/current results, exercise error/late reply/context-label/fresh-session recovery, and verify metadata edits retain meshes with exact canonical geometry.
