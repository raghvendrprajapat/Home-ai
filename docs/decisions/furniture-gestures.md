## Interrupted pointer ownership

Blur/hidden cancels previews but retains held touch IDs as blocked. A nonprimary second finger cannot restart editing. A genuinely new primary touchDown retires orphaned IDs when a prior browser pointerup was missed; a still-held first finger cannot emit another native down, and its secondary finger reports isPrimaryfalse. Existing mouse missed-up/blur recovery remains unchanged. A remounted canvas has no previous IDs, so a nonprimary first event is admitted only as a blocked owner until released, never an edit. Outside/control touch arbitration runs in capture phase so a control's bubble stopPropagation cannot hide its second finger. The pointer coordinate frame is captured after primary recovery.
