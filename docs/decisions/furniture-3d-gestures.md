## Interaction and geometry

Orbit remains the default. Select an existing visible furniture item, then choose **Move selected furniture** or **Rotate selected furniture**. The explicit free checkbox or Shift bypasses the default50mm centre grid / absolute15degree angle steps. A3px final displacement is still a tap; precision inputs/buttons remain available. Touch uses the existing150ms hold convention; early motion in an explicit transform mode cancels the edit. Use Orbit mode for camera movement. A second pointer cancels rather than rotating furniture with two fingers.

The same nearest-visible-hit resolver used for picking returns the actual world hit, including canonical IDs for instances and structural occlusion. The projection plane passes through that hit's worldY, preserving the grab offset on a raised/top surface; the canonical elevation never changes. PlanX/Ymm correspond to ThreeX/Zmetres. An owned camera/world/projection/viewport snapshot maps raw fractional pointer positions into a validated integer-mm command; near-parallel, behind-eye, nonfinite, clipped and outside-viewport candidates reject. Near/far use camera clipping depth, not radial distance. BrowserDOMRect properties are copied explicitly because native getters do not survive object spread. Release outside the drawing viewport cancels; it cannot apply the last valid preview.

## Ownership and canonical consistency

One document-capture dispatcher routes transforms before ordinary picking and OrbitControls; unowned camera releases retain their original handlers. Acquiring a transform requires a canonical framebuffer draw of the current full project/session/generation/dependency tag and an already selected actual hit. `start()` may synchronously change ownership or dispose the view: recheck the closed state, selectedID, mode, full tag and eligibility before installing the owner. A pending-status callback cannot schedule work after synchronous disposal.

`controls.enabled=false` alone does not freeze damping/autoRotate. Acquisition disables all three flags, drains residual orbit deltas through public updates, then restores the **exact** captured position/quaternion/target after the final update. The animation loop skips controls updates and camera clamping while a gesture owns the camera. Frozen matrix equality detects any later mapping change. Camera APIs/keyboard, resize, scroll, selection/tag/mode/free changes, context loss, blur/hidden, cancellation and unmount retire the proposal. A fresh primary touch recovers orphaned IDs; nonprimary touches remain blocked across blur/remount. New primary mouse streams retire missed mouse releases without discarding held touch ownership.

At most one preview is prepared per RAF. Core-model validates every proposal; only derived furniture presentation changes, through SceneAdapter.refreshFurniture. LoadedGLBs, instances, fallbacks, outlines and overlap advisories consume the same effective preview document. Late GLB completion may present it only behind the applied canonical tag fence. Placement/property previews surrender exclusive ownership before direct manipulation begins.

Final release constructs and validates its own candidate, captures its command, **clears the preview and restores the last CPU-applied canonical GPU document, then executes exactly once**. A failed restoration prevents the command. This order matters: if the subsequent worker fails, the retained previous-generation scene contains the actual previous canonical transforms, never unconfirmed preview transforms. Store edits/Undo still use existing atomic core commands and monotonic generations. No mesh worker request is issued by previewing. Preview frames cannot acknowledge a canonical generation/performance reading. JSON export reads canonical data;3DPNG capture rejects an active gesture.

Capture/preview/status/reporting faults are contained. Canonical restoration, camera flags, capture release and status cleanup run as independent cleanup steps; one failure cannot skip the others. Timers, RAF, store/window/document listeners and model/resource owners retire on teardown. Failure reporting itself is not a cleanup dependency.
