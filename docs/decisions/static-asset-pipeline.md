# D39 — static original asset pipeline foundation

PH4-T01, Codex under D17/D36,2026-10-15; base PR85 merge42b95c0434cc4e6c942048b36e78f562b66262a8. This implements the local static/untextured portion of TRD-012/AST-001…003. R2 delivery, textured imports/KTX2 and device-selected compression remain pending; no cloud or mobile-optimization preparation is authorized by this decision.

- Authoring uses a narrow original-box JSON profile in integer millimetres. Source dimensions/labels/parts/provenance/rights are checked before generation. No external model, art, texture or user upload is admitted. The pilot desk has an asymmetric front drawer so its orientation can actually be tested.
- gltf-transform/core4.5.1 writes/reads GLB; official Khronos gltf-validator2.0.0-dev.3.10 must report0errors, with warnings/infos retained separately. These pinned development-only dependencies and property-graph4.1.0 have official license metadata and tarball-integrity evidence; they are not browser imports. No gltf-transform image-functions dependency is needed yet.
- Correct AST-003 grounding to glTF **minimumY=0**, X/Z centred, metres, front−Z. The prior “minimumz=0” conflicts with glTFY-up and the spec's own D.12; canonical planZ-up remains unchanged. Independent decoded vertices prove the1200×600×750mm desk is1.2×.6×.75m, with front detail at negativeZ, outward winding and positive closed volume.
- Admission rejects external buffers, textures/images, skins/animation/cameras/extensions, morph targets and non-triangle modes. Scene transforms, dimensions/ground/centre, actual placed triangle count and2MiBbinary cap are checked. Current original output has72triangles; LOD0/LOD1 may share exactly the same uncompressed file because it already meets both≤20000/≤3000budgets. This is not simplification, compression or device performance evidence.
- The deterministic256pxSVG thumbnail is original/stylized; it is not a photoreal render. GLB and thumbnail paths carrySHA256; records pinID/version, source hash, dimensions and rights. No premium/entitlement field or R2 adapter is added before D36 permission.
- Rights type `project-original-app-use` records original procedural output generated by Codex for the authorized app, attribution, source path/URL/hash, fixed checkedOn, commercialUse/app redistribution and no standalone redistribution grant. Owner rights are retained. It makes no CC0/exclusive-authorship/copyrightability claim. CI verifies record completeness/provenance and bytes; this is not independent legal clearance.
- `assets:build` compiles/validates everything, preflights output names, skips already-matching immutable blobs and writes changed/new blobs to unique siblings before rename. All blob checks precede the last catalog rename. A normal build never rewrites existing matching files. Failures before manifest publication retain the prior catalog/referenced blobs. This is a single-writer development build contract, not fsync/multi-file/concurrent-writer/process-death durability; interrupted builds can leave their own stale temporaries or unreferenced new blobs that `assets:check` reports. Never delete unknown files automatically.
- `assets:check` regenerates and compares every artifact read-only. `assets:versions` compares current entries against a Git commit baseline, preventing joint source/catalog/blob edits from silently replacing an existingID/version. GitHub Check fetches history and supplies PRbase/pushbefore; missing CI baseline fails, manualdispatch usesHEAD^, local checks useorigin/main. Historical entries remain byte-equivalent; add a new version instead of deleting/rewriting one. The first pilot baseline contains0historical versions. This guard depends on the correctly reviewed CI baseline, not an adversarial-maintainer trust boundary.

Commands and executable evidence are in [tools](../../tools/asset-pipeline/README.md) and [verification](../verification/ph4-t01.md). Full catalog loading/placement is PH4-T02/T03; all D36 gates and optional C1 walkthrough remain pending.
