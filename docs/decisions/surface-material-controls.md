# D49 — visible canonical surface colours

2026-10-16 · PH4-T04 stage C · Codex under D17, subject to D36.

The inspector offers wall-side and room-floor paint in both views. A wall's left/right labels include the cardinal direction derived from its current A→B orientation; reversing a wall changes these labels consistently with the existing reverse command. Five original local solid-colour defaults supplement existing project finishes. Imported material IDs/definitions and user names are preserved; an ID already present in the drawing takes precedence over the local default. The UI explicitly says patterns/textures are not available. No remote/proprietary texture is added.

New blank projects previously had one base material. ApplySurfaceMaterial atomically installs a missing library definition and changes one target binding, so one Undo restores both. Existing material definitions cannot be overwritten by paint: a conflicting existing-ID definition rejects the command. Missing/invalid targets, malformed definitions, global ID collisions and invalid schema candidates reject the entire transaction with the model/history unchanged. The command never writes geometry or unrelated room properties. Pure paint increments only directly changed entity revisions; inherited geometry-dependency revision propagation is skipped for this command because no wall/opening/room geometry changed. Renderer material dependencies still derive from current canonical IDs, not revision counters. Other commands retain their prior semantics.

Room property draft effects now track name/type/height separately from floor finish, so an immediate floor swatch neither applies nor discards an unsaved room-name draft. Paint is one immediate canonical command; choosing the already selected finish is a no-op. Current-ID swatches and room-list colours read canonical definitions.

Both Konva and the exported plan PNG derive the same wall-side colour strips from accepted owner footprints: clip each rectangle at the host centreline, assign north/south/east/west halves by A→B direction, drop only zero-sized display strips and preserve the exact full rectangle coverage. This is presentation geometry, not room/wall topology. Room floors use their floorMaterial baseColor. Selection uses outlines rather than replacing paint colours. The 3D renderer retains its established cap/side assignment; 2D strips represent the two side finishes rather than a physical top-face render. Material IDs are shared; 3D PBR lighting legitimately changes visible RGB compared with flat2D swatches.

A paint intent owns project/session/generation/dependency tag, target/side/material, a monotonic UI-context epoch, button rectangle and input sequence. It cannot retarget after selection, mode roundtrip, Undo/Redo, deletion or locale changes. Pointer release must belong to the armed button and remain within a6px movement threshold; secondary/nonprimary pointers, cancel, focus loss, Escape, hidden state and actual scroll movement retire the intent. Native Enter/Space support repeat suppression. Assistive click-only activation is admitted when no cancelled physical intent is pending. A rejected stale activation asks the user to activate again. Explicit DOMRect fields avoid native-getter spread mistakes. Beginning material interaction retires competing drawing/furniture previews.

The held-pointer set is cleared on blur/hidden after retiring the intent. Otherwise a missing pointer-up could strand paint permanently; the permanent regression first reproduces that failure and then verifies a fresh trusted primary native touch succeeds. A continuing nonprimary touch cannot acquire a new intent. Queued scroll events with an unchanged button rectangle do not cancel a valid intent; actual movement does. All document/window listeners are removed on unmount.

Tests combine analytic side/rectangle cases and100seeded translation/thickness/reversal properties; canonical blank-library paint/one Undo/no-op/invalid rejection and owner-tag cases; actual2D/PNG/3D pixels; opposite-side and exact neighbor isolation; save/reload; room draft preservation; Hindi; and delivered native held-pointer/Space/view-roundtrip/multi-touch/lost-release regressions. Counts, failures and final evidence are in verification/ph4-t04c.md and its JSON. Self-audit is not independent certification. Physical-device200ms, accessibility/external review and broader material/texture corpora remain pending. Furniture variants are Should scope and remain separate.

No new dependency, canonical schema migration, accepted fixture, immutable asset or owner-research change. D36 accounts/cloud/history, mobile optimization/sharing/real-phone testing, billing/security/privacy/release/final-Claude scopes remain unstarted. Existing automated Linux/browser/Android debug checks are ordinary regression validation.
