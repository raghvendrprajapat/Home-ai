## Architecture and invariants

The 2D and 3D views subscribe to the same private core-model store. No renderer object enters serialization. Canonical coordinates remain integer mm; mesh derivation uses exact half-mm rectangles, then converts once to Three's `(x/1000, height/1000, planY/1000)` metre frame. Floor elevation is included once. Furniture placeholders use their real dimensions and `rotation.y = -rotationDeg`.

The pure CPU builder uses the spec's orthogonal cell alternative without CSG:

1. Divide height at wall tops and opening sills/tops. Calculate caps from walls active in each band, so short/tall L/T joins remain closed.
2. Cut each opening from its host before solid-union ownership. Another wall's overlapping solid is not incorrectly removed.
3. Partition the band into disjoint owner rectangles and extrude them. Cancel opposing internal surfaces across owners and height bands.
4. Union coplanar exposed fragments per owner/material/normal. This removes incidental height subdivisions on unrelated walls.
5. Split shared edges at the same coordinates and triangulate outward. Window sill/lintel/jambs and door voids are actual surfaces; no decorative box fills a hole.
6. Build room floors from their exact clear rectangles. Each sill-zero door owns one threshold across wall thickness. Windows receive no threshold; room areas never include thresholds.

`CachedSceneBuilder` skips geometry construction for furniture/name-only changes and compares complete exposed-face, shared-edge and UV dependencies before emitting each mesh buffer. It does not rely on a reused entity revision or a collision-prone hash. Changed geometry still invokes conservative full union/dependency analysis; only affected buffers and GPU geometries are replaced. This remaining CPU cost must be measured in PH0-T06 before claiming phone responsiveness.

The worker transfers buffer copies so its retained cache is not detached. One build is in flight; intervening commits coalesce into the latest snapshot. All `{projectId, sessionId, localGeneration, dependencyHash}` fields must match before a result can enter the adapter. During an update the old scene is hidden rather than presented as current. Undo/redo uses a new generation. Closing a view terminates its worker; a 10-second watchdog terminates a stuck build.

The imperative Three adapter reuses identical typed buffers/materials and disposes replaced/removed resources. Three loads lazily, with orbit and keyboard controls, hemisphere/directional lighting, sRGB output and ACES tone mapping. Pixel ratio is bounded at 1.5; antialiasing/shadows/textures are deliberately absent from this proof. Frame rendering invalidates on scene/camera/viewport changes, rather than redrawing an idle scene on every RAF. Worker startup, lazy-load and WebGL initialization failures preserve the live project and offer 2D continuation. Context restoration uses retained CPU geometry. These behaviors do not imply that unsaved edits survive reload.

D19 records prototype work/surface/vertex limits as **3D-only errors**, never silent model changes or room filtering. They are not validated mobile performance tiers.
