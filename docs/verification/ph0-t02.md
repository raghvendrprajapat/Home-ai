## Implemented contract

`packages/geometry` has no DOM, React, network or renderer imports. It validates finite integer-mm coordinates, ±100000-mm domain, wall length ≥10 mm, thickness 50–1000 mm, height 1000–6000 mm, endpoint/floor identity, global geometry IDs and duplicate supplied room ownership. Saved topology rejects unjoined intersections, overlaps, diagonal walls and four-way/X junctions.

The pure `applyGeometry` transaction returns the identical original Plan on rejection. Add/move/delete candidates normalize overlap unions and T nodes, retain the original wall ID on its longest child, derive positive Y-down half-edge faces and recalculate room IDs/properties before returning. Both renderers will consume the returned derived geometry; only core-model will commit canonical data.

L0 footprints use exact perpendicular half-thickness offsets and D18 square free-end caps. An event sweep partitions their union into disjoint wall-owned rectangles, so the area sum equals union area. Floor regions use the same occupied strips, not centreline area; scanline subtraction and boundary tracing also support concave rooms and dead-end stubs. Positive disconnected clear components remain part of their bounded face (D12); unsupported islands/holes reject. Geometry is exact in half-mm coordinates, with no raster approximation in production.

Exact room cycles preserve identity. Spatially bounded overlap tests apply the specified IoU/split/merge rules otherwise. An ambiguous split/merge returns a clear `ambiguous-room` error rather than moving a name silently; a user-resolution command/UI remains a later task. Internal endpoint/degree indices, supporting-line lineage groups and sparse room-overlap candidates avoid unnecessary global pair scans. The spatial grid has a bounded overflow path for long boxes and is checked against an exhaustive independent test oracle.
