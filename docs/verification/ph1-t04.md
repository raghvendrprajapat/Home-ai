## Low/Mid phone procedure — pending issue15

Use this PR's green Android debug artifact and existing backup/debug-key instructions. Launcher **GharPlan**, debug package `com.gharplan.app.debug`. Do not uninstall/clear any drawing-bearing app merely to install a mismatched debug key.

1. On both phones, create a **new named test drawing**, add starter room; inside area14.44m². Move right X4500mm →16.34m²; wait for truthful local save. Test English and Hindi.
2. Press Export drawing; choose a local Documents/Downloads folder, save `gharplan-project.json`. Confirm the app reports verified write/readback. If it reports cancellation/failure/in-progress, treat the external file as unverified; current drawing/JSON fallback remain. Later edits need another export.
3. In the phone's Files app confirm the chosen file exists and has nonzero size. App readback is stronger than this manual check; size alone is not geometry proof.
4. Projects → Import drawing → select that file. Existing-ID preview must permit only a **separate copy**. Cancel: no new drawing. Import again as copy: source remains and copy has the same measured content. Trash the source; importing must not silently revive it.
5. For an exact-ID restore, transfer your **new test drawing** file to the other phone with a fresh/different local collection, then import using “Open backup with original IDs.” Check name, units,14.44/16.34 measurement state,2D/3D and reopen. Existing identities still require copies.
6. The export→clear app storage→import gate may be run **only on a disposable debug installation after every needed drawing has a verified independent backup**. Never clear the production package. Choose the external file after app restart; its absent original identity/content should restore. This step is not executed by Codex and is not needed to test cloud setup.
7. Repeat provider/cancel coverage: cancel picker (no success), local Downloads/Files, Drive if used; provider failure/readback denial must not show success. If killing during picker/write, treat file as unverified and recover local drawing; record exact loss/status. Source/receipt tests do not prove this lifecycle gate.
