## Result and implementation

Capacitor 8.5.3 packages the existing editor, worker, lazy Three view and disposable `/perf` lab as local assets over private `https://localhost`. The provisional production ID is `com.gharplan.app`; debug installs use `com.gharplan.app.debug`. No remote server URL, service credential, signing key or unrestricted navigation policy is configured. Cleartext/mixed content and application backup are disabled. The FileProvider is non-exported and scopes future exports to its cache `exports/` directory. An explicit OEM transfer policy remains necessary before private durable projects/release.

The debug-only `perf` intent selects the lab on a cold start; the benchmark guide force-stops only the debug package first because `singleTask` does not rerun `onCreate` for an already-running activity. Android lab export reports that native download is unimplemented and retains JSON for USB inspection; normal browser export still downloads it. No native Filesystem/share capability is implied.

CI adds an **Android debug** job after **Check**, with pinned Java/action versions, frozen dependencies, web sync, SDK preparation, compilation/lint, actual APK signature/config/manifest/asset inspection and seven-day artifact retention. The artifact includes matching web `dist` assets so Chrome/WebView comparison uses the same build. A local green build does not establish GitHub CI; merge must wait for both exact-head jobs. Issue #10 stays open while its physical benchmark portion is outstanding.
